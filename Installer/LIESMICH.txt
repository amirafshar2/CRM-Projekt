Schraubwerk CRM – Demo-Version
==============================

Installation
------------
1. ZIP-Datei entpacken (Rechtsklick -> "Alle extrahieren").
2. "Installieren.cmd" doppelklicken.
   - Ist SQL Server Express LocalDB noch nicht vorhanden, wird es automatisch
     von Microsoft geladen und installiert (Windows fragt einmal nach Admin-Rechten).
   - Das Programm wird nach %LOCALAPPDATA%\Programs\SchraubwerkCRM kopiert.
   - Verknüpfungen auf dem Desktop und im Startmenü werden angelegt.
3. Das Programm startet automatisch. Beim ersten Start werden Datenbank und
   Demo-Daten angelegt (einige Sekunden).

Anmeldung: Benutzer "demo", Passwort "demo123" (wird automatisch eingetragen)
Zweiter Benutzer mit eingeschränkten Rechten: "m.schulz" / "demo123"

Hinweis: Falls Windows SmartScreen warnt ("Der Computer wurde geschützt"),
auf "Weitere Informationen" -> "Trotzdem ausführen" klicken. Das Programm ist
nicht digital signiert, weil es ein Portfolio-Projekt ist.

Deinstallation
--------------
Startmenü -> "Schraubwerk CRM" -> "Schraubwerk CRM deinstallieren"
(optional wird auch die Demo-Datenbank gelöscht).

Voraussetzungen: Windows 10/11 (64 Bit), .NET Framework 4.7.2 (bei Windows 10/11 enthalten).
